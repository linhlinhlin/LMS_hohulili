🎯 MISSING/RECOMMENDED ENDPOINTS
-------------------------------------------
1. GET /api/v1/admin/courses/{courseId}/enrollments
   - Lấy danh sách enrollment của 1 khóa học với thông tin chi tiết
   - Response: enrollment date, progress, last accessed

2. DELETE /api/v1/admin/courses/{courseId}/enrollments/{studentId}
   - Xóa enrollment của 1 học viên khỏi khóa học

3. GET /api/v1/admin/users/{userId}/enrollments
   - Lấy tất cả khóa học mà user đã đăng ký

4. POST /api/v1/admin/courses/{courseId}/bulk-unenroll
   - Xóa nhiều học viên khỏi khóa học cùng lúc

5. GET /api/v1/admin/enrollments/stats
   - Thống kê enrollment theo thời gian (monthly/weekly)

6. PATCH /api/v1/admin/courses/{courseId}/status
   - Thay đổi trạng thái khóa học trực tiếp (DRAFT/APPROVED/REJECTED)

7. GET /api/v1/admin/courses/search
   - Tìm kiếm nâng cao với nhiều filter (status, teacher, date range)

📝 NOTES CHO FE ADMIN
-------------------------------------------
1. Tất cả API trả về format chuẩn:
   {
     "success": true/false,
     "data": {...},
     "message": "..."
   }

2. Pagination format:
   {
     "content": [...],
     "totalElements": 100,
     "totalPages": 10,
     "size": 10,
     "number": 0
   }

3. Course Status Values:
   - DRAFT: Khóa học đang soạn thảo
   - PENDING: Chờ admin duyệt
   - APPROVED: Đã được duyệt, hiển thị công khai
   - REJECTED: Bị từ chối

4. User Roles:
   - ADMIN: Toàn quyền
   - TEACHER: Quản lý khóa học của mình
   - STUDENT: Đăng ký và học

5. JWT Token:
   - Expires: 24 hours
   - Refresh token: 7 days
   - Header format: "Authorization: Bearer <token>"

6. Error Codes:
   - 400: Bad Request (validation error)
   - 401: Unauthorized (missing/invalid token)
   - 403: Forbidden (insufficient permissions)
   - 404: Not Found
   - 500: Internal Server Error
