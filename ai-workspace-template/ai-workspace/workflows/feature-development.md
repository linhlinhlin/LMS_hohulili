# Feature Development Workflow

---

## Steps

1. **PM**: Receive and analyze requirement
2. **PM**: Break down into tasks, assign agents
3. **Agents**: Implement their parts
4. **QA**: Verify implementation
5. **PM**: Review and close

---

## Checklist

- [ ] Requirement clear
- [ ] Tasks assigned
- [ ] Implementation done
- [ ] Tests written
- [ ] Verified working
- [ ] Progress updated
