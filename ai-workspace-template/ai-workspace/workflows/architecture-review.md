# Architecture Review Workflow

---

## When to Use

- Major architectural changes
- New module/component design
- Tech stack changes

---

## Steps

1. **PM**: Define scope of review
2. **Relevant Agents**: Provide domain input
3. **Discussion**: Evaluate options
4. **Decision**: Document in decision-log.md
5. **Update**: Update global-architecture.md

---

## Checklist

- [ ] Scope defined
- [ ] All stakeholders consulted
- [ ] Options evaluated
- [ ] Decision documented
- [ ] Architecture docs updated
