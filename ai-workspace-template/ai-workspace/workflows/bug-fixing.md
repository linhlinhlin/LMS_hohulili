# Bug Fixing Workflow

---

## Steps

1. **Report**: Document bug in shared-board.md
2. **QA**: Analyze and reproduce
3. **Assign**: Route to appropriate agent
4. **Fix**: Implement fix
5. **Verify**: QA verifies fix
6. **Close**: Update status

---

## Bug Report Template

```markdown
## BUG-XXX: [Title]

Severity: Critical | High | Medium | Low
Reported: [DATE]
Owner: [Agent]

### Steps to Reproduce
1. Step 1
2. Step 2

### Expected
[Expected behavior]

### Actual
[Actual behavior]

### Fix
[How it was fixed]
```
