# Agent Handoffs

Protocol for transferring work between agents.

---

## Handoff Template

```markdown
## HANDOFF: [From Agent] → [To Agent]

Date: [DATE]
Priority: High | Medium | Low

### Context
[What was done]

### Task for You
[What needs to be done]

### Files to Check
- [file1]
- [file2]

### Acceptance Criteria
- [ ] Criterion 1
- [ ] Criterion 2
```

---

## Handoff Rules

1. Document what was done
2. Specify exactly what's needed
3. List relevant files
4. Update shared-board.md
