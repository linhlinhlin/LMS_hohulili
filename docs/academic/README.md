# Academic artifacts

Tài liệu phục vụ luận văn / phản biện / bảo vệ học thuật. Tách riêng khỏi `docs/` chính để không lẫn vào docs kỹ thuật.

## Nội dung

- `response-to-reviewers.md` — trả lời phản biện (tiếng Anh)
- `giai-trinh-phan-bien.md` — giải trình phản biện
- `ghi-chu-huong-phan-bien.md` — ghi chú hướng phản biện
- `phieu-tra-loi-phan-bien.md` — phiếu trả lời phản biện

## Nguyên tắc

- Giữ ngôn ngữ gốc (tiếng Việt cho phản biện tiếng Việt, tiếng Anh cho reviewer quốc tế).
- Không xóa ngay cả khi luận văn đã bảo vệ — là bằng chứng học thuật.
- Cập nhật khi nhận phản biện mới hoặc chỉnh sửa theo yêu cầu giáo viên hướng dẫn.
