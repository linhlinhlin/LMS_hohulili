# Superpowers Docs

Thư mục này chứa các tài liệu sinh ra từ workflow design/spec của agent.

## Vai trò

- lưu spec/handoff trước khi triển khai
- giúp team code theo cùng một hướng khi feature đủ lớn hoặc đủ phức tạp

## Lưu ý

- đây không phải nơi giữ runtime truth lâu dài
- khi feature đã ship và ổn định, phần còn sống cần được promote sang `docs/architecture/`, `docs/reference/`, `docs/runbooks/`, hoặc `docs/testing/`
