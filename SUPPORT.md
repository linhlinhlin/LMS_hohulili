# Support

Use the right channel so the team can respond quickly.

## Questions and usage help

- Start with `README.md`, `AGENTS.md`, and `docs/README.md`.
- For local setup, read `CONTRIBUTING.md` and `docs/reference/LOCAL_DEV_MATRIX.md`.
- For production or deploy, read `docs/runbooks/`.
- For PWA/offline, read `docs/runbooks/PWA_OFFLINE_RUNBOOK.md`.
- For Google login, read `docs/runbooks/GOOGLE_LOGIN_GIS_SETUP_RUNBOOK.md`.

If the question is still unclear, open an issue with the closest matching issue form.

## Bugs

Open a Bug report issue and include:

- Environment and route.
- Steps to reproduce.
- Expected and actual result.
- Logs, screenshots, or console errors.

## Feature requests

Open a Feature request issue and include:

- User problem.
- Acceptance criteria.
- Affected role.
- Risks or alternatives.

## Security

Do not open a public issue for vulnerabilities. Follow `SECURITY.md`.

## Repository operations

For labels, branch protection, GitHub Actions, or repo settings, use:

- `docs/reference/GITHUB_GOVERNANCE.md`
- `docs/runbooks/GITHUB_PROFESSIONAL_SETUP_RUNBOOK.md`
- `scripts/github/audit-repo-settings.ps1`
- `scripts/github/sync-labels.ps1`
