# Code of Conduct

HoHoLiHu Maritime LMS is a learning infrastructure project. We expect collaboration to be direct, respectful, and focused on making the system safer and better for learners, teachers, operators, and maintainers.

## Expected behavior

- Be respectful and precise when giving feedback.
- Critique code, process, and decisions without attacking people.
- Prefer evidence: reproduction steps, logs, screenshots, docs, or tests.
- Keep review comments actionable and scoped to the pull request.
- Assume good intent, but do not ignore risk.
- Use professional Vietnamese or English with clear meaning and correct accents.

## Unacceptable behavior

- Harassment, personal attacks, insults, or discriminatory language.
- Publishing private credentials, secrets, production data, or personal data.
- Publicly disclosing security vulnerabilities before maintainers can investigate.
- Intentionally disrupting CI, production, or contributor workflow.
- Repeated off-topic comments that make review or triage harder.

## Enforcement

Maintainers may edit or hide comments, close issues, block contributors, or restrict access when behavior harms the project or team. For security issues, follow `SECURITY.md` instead of public discussion.

## Reporting

Report conduct issues privately to a maintainer or repository owner. Include links, screenshots, or context when possible so the team can respond fairly.
